團員可自由修改自己的海報。只有具備 GitHub 專案寫入權限的人，才能發布正式共用資料。

① 選擇花種底圖

② 花農名單

每行一個名字，支援日文、Emoji 和特殊符號。 海報會自動加上 🪄，不加圓點或編號。

③ 日期

④ 本日總召

⑤ 調整文字與位置

日期、總召和每個花農名字可獨立調整。可用滑桿或在預覽圖片上直接拖曳。

⑥ 管理員｜發布共用資源

你可以在網站完成共用名單、花種名稱和各張海報排版後，按下方按鈕複製正式資料，再貼到 GitHub 的 shared.json 並提交。
只有具有 GitHub 寫入權限的人能發布。
